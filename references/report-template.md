# Reader-Friendly Markdown Report Template

Use this as a maximum structure. Remove sections that do not improve the decision.

Default audience: Amazon operator, product manager, or business owner without analytics training.

Rules:

- Put conclusions and actions before formulas.
- Use Chinese business questions as headings.
- Expand every acronym on first use.
- Do not show internal component acronyms in the default report.
- Put KIMS, CKAF, TM, SM, formulas, and detailed scores in an optional appendix.
- When historical demand evidence is absent, write `市场趋势无法判断`; do not use a placeholder number.
- End every analytical section with `这对经营意味着什么`.
